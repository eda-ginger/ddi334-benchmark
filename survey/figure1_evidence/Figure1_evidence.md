This document shows where every number in **Figure 1** comes from: how many of the surveyed DDI-prediction papers use each dataset, and the minimum and maximum dataset size (drugs, DDIs, interaction types) that those papers report.

Everything below is generated by `gen_fig1_evidence.py` from a CSV export of the hand-curated sheet (`snapshot/`); nothing was typed in by hand except the one row in `manual_additions.csv`.

## 3. How it was made

1. **Reading the papers.** For every paper in the corpus (84 papers) the dataset it uses and the dataset statistics it reports were read from the paper and entered in a Google Sheet (tabs `ddi` for DDI datasets and `KG` for knowledge graphs). Papers that report the same numbers share one row.
2. **Exporting.** Each tab was exported unchanged to CSV (`snapshot/`).
3. **One row per paper.** The script splits every sheet row into one row per paper and matches the names to the corpus (three names are aliased: `AAE-KGE`, `HKG-DDIE`, `Zhang et al.` = `KGC-LSTM`). An unmatched name stops the script.
4. **Counting rules.**
   - *R1:* a paper that was removed from the corpus is not counted (SCAT / SCATrans).
   - *R2:* a knowledge-graph paper that merges several sources is counted under *Combine* only, not under single-source rows such as DrugBank - kg or KEGG (Karim et al., Celebi et al., KGE-MFL).
   - The `count` column of the sheet is ignored; the number of papers is the number of distinct matched names.
5. **Ranges.** For each dataset the script takes the smallest and largest drugs / DDIs / interaction types over the counted rows (unreported values are skipped) and records which papers give them.
6. **Check.** The result is compared with the numbers used to draw Figure 1 (`figure1_values.csv`). All 13 datasets match.

Rebuild: `python gen_fig1_evidence.py` writes `Figure1_evidence.xlsx`, `per_paper.csv`, `ranges.csv` and this file.
